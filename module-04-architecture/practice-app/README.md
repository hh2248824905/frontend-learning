# practice-app（模块四 · 应用架构）

占位目录，第 9 周起填充。

## 计划

| 单元 | 要落地的目录 | 内容 |
| --- | --- | --- |
| 9 | `src/router/` | 路由表、路由守卫、鉴权拦截 |
| 10 | `src/stores/` | Pinia 登录态模块 |
| 10 | `src/api/` | 请求层封装（实例、拦截器、统一错误处理） |

## 验收：鉴权闭环

- [ ] 未登录访问受限路由 → 跳登录页并记住来源地址
- [ ] 登录成功 → 写入状态，跳回来源页
- [ ] 刷新页面 → 状态不丢（持久化）
- [ ] 退出登录 → 清空状态并回到登录页
- [ ] 接口 401 → 请求层统一拦截并跳登录页
