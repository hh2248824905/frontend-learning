# 模块四 · 应用架构

8 学时 · 第 9-10 周 · 单元 9-10

把零散页面组织成多页面应用：路由负责地址与界面的对应，状态管理负责跨页面共享的数据，请求层负责与后端打交道。从本模块开始，练习代码同时落入综合项目。

## 单元

| 单元 | 主题 | 主要位置 | 课堂产出 |
| --- | --- | --- | --- |
| 9 | 路由 Vue Router 与登录鉴权 | `practice-app/src/router/` | 带鉴权的页面骨架 |
| 10 | Pinia 状态管理与数据请求层 | `practice-app/src/stores/`、`src/api/` | 登录态状态模块、请求层封装 |

## 目录约定

```
practice-app/src/
├── router/
│   ├── index.js       路由表与全部路由配置
│   └── guards.js      全局守卫：登录判断与权限拦截
├── stores/
│   ├── user.js        登录态、角色、凭证持久化
│   └── ...            按业务域拆分，一个域一个模块
├── api/
│   ├── request.js     axios 实例、拦截器、错误分层
│   └── <模块>.js      按业务模块划分的接口函数
└── views/
```

接口地址不写在组件里，组件只调用 `api/` 里的函数。全局状态只在确实跨页面共享时使用，页面内数据留在页面内。

## 鉴权闭环的要求

未登录访问受限页面时跳转登录页，登录成功后回到原地址；刷新页面登录态不丢失；凭证失效后自动清除并回到登录页。角色差异要同时落在菜单、路由守卫与按钮三处。

## 跑起来

```bash
cd practice-app
pnpm install
pnpm dev
```

第 10 周的课堂任务是限时独立完成鉴权闭环，作为阶段性考核内容，建议保留每个阶段的提交记录。
