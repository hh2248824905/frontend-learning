# 模块四 · 应用架构

8 学时，第 9-10 周。练习工程为 `practice-app/`。编码工作从这里开始逐步收拢进综合项目 `campus-activity-admin/`。

| 单元 | 主题 | 代码位置 | 课堂产出 |
| --- | --- | --- | --- |
| 9 | 路由 Vue Router 与登录鉴权 | `practice-app/src/router/` | 带鉴权的页面骨架 |
