## 一、基线版本

| 工具 | 要求版本 | 本机实际 | 是否达标 |
| --- | --- | --- | --- |
| Node.js | 22.12 LTS 及以上 | | |
| 包管理器 | pnpm（统一） | | |
| Git | 2.40 及以上 | | |
| 编辑器 | VS Code / IntelliJ IDEA | | |

```bash
# 一条命令查看基线
node -v && pnpm -v && git -v
```

## 二、包管理器配置

| 检查项 | 说明 | 结论 |
| --- | --- | --- |
| 镜像源 | `pnpm config get registry`，国内建议指向镜像站点 | |
| 全局存储位置 | `pnpm store path`，确认不在系统盘或已预留空间 | |
| 与 npm 混用 | 同一工程只保留一种 lock 文件 | |

## 三、网络与代理

| 检查项 | 说明 | 结论 |
| --- | --- | --- |
| 依赖安装 | `pnpm install` 能在目标工程跑通 | |
| 远端推送 | `git ls-remote origin` 能返回分支列表 | |
| 代理干扰 | 代理开启时依赖下载与 Git 推送均正常 | |

## 四、开发服务器

| 检查项 | 说明 | 结论 |
| --- | --- | --- |
| 启动 | `pnpm dev` 能起服务且无报错 | |
| 访问地址 | 确认监听地址（`127.0.0.1` 或 `[::1]`），浏览器能打开 | |
| 端口占用 | 默认端口被占用时能改端口或杀掉占用进程 | |
