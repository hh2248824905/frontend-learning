# 课程资料

本目录存放《前端工程化开发》配套的过程性资料，**不参与构建**，可随课程进度持续补充。

| 文件 / 目录 | 内容 | 对应单元 |
| --- | --- | --- |
| `env-checklist.md` | 环境自检清单 | 单元 1 |
| `issue-log.md` | 问题记录表 | 全程 |
| `notes/` | 学习笔记与课堂笔记 | 全程 |
| `notes/前端学习笔记.md` | 前端知识速查（HTML / CSS / JavaScript / TypeScript / 框架 / 工程化） | 全程 |
| `notes/前端知识体系总结.md` | 前端知识体系总结 | 全程 |
| `notes/课堂笔记/` | 逐次课堂笔记与配图 | 全程 |

## 约定

- `notes/` 下的笔记保持原有相对路径，配图放在同级 `assets/` 内，便于用任意 Markdown 工具打开。
- 每完成一个单元，在 `issue-log.md` 补一条记录；环境自检清单在换机或重装后重新核对一遍。
