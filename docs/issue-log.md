## 记录要点

1. **写现象而不是写判断**。把报错原文贴上，不要只写「启动失败」。
2. **写定位过程**。哪条命令、哪个日志、哪一步缩小了范围。这部分比结论更值钱。
3. **写根因**。如果只是「换个写法能跑」但不知道原因，标注为待查。
4. **写可复用的解决动作**。命令、配置片段，能直接复制走。
