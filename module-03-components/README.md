# 模块三 · 组件化开发

8 学时 · 第 7-8 周 · 单元 7-8

把页面拆成能复用的积木，再把重复逻辑抽成组合式函数。本模块的产出会成为综合项目里的组件基础。

## 单元

| 单元 | 主题 | 主要位置 | 课堂产出 |
| --- | --- | --- | --- |
| 7 | 组件基础与父子通信 | `practice-app/src/components/` | 自研卡片组件、可自定义单元格的表格组件 |
| 8 | 组件进阶与逻辑复用 | `practice-app/src/composables/`、`src/directives/` | 可复用弹窗与全局通知、自研组合式函数集 |

## 目录约定

```
practice-app/src/
├── components/
│   ├── base/          基础组件：卡片、按钮、表格、弹窗
│   └── business/      业务组件：与具体场景绑定的组装组件
├── composables/       组合式函数，一个文件一个函数
├── directives/        自定义指令：聚焦、防抖、权限控制
└── views/             本模块的练习页面
```

基础组件与业务组件分目录存放，这条约定在综合项目里同样适用。

## 拆分判断依据

按三条标准判断一个区块是否值得抽成组件：是否会被复用、是否会独立变化、当前文件是否已经过于臃肿。只满足第三条时，优先按职责切而不是按代码行数切。

## 接口设计

每个自研组件在文件的说明注释里写清三件事：接收哪些属性（含类型与默认值）、会抛出哪些事件（含载荷结构）、提供哪些插槽。综合项目的组件评审按这份说明逐条对照。

## 跑起来

```bash
cd practice-app
pnpm install
pnpm dev
```
