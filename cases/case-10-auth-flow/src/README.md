# 源码目录

> 案例 10 · 登录鉴权闭环 ｜ 归属单元 9 ｜ 挑战 ｜ 课堂演练

本目录存放该案例的源码。

## 目录约定

```
src/
├── App.vue          根组件，页面入口
├── main.js          应用入口
├── components/      本案例内复用的组件
├── composables/     组合式函数（把状态与逻辑从组件里抽出来）
└── assets/          样式与静态资源
```

单文件组件用 PascalCase 命名；一个组件一个文件，避免出现八百行的 App.vue。

## 运行

```bash
pnpm install
pnpm dev
```
