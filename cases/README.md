| 档位 | 面向 | 案例特征 | 案例 |
| --- | --- | --- | --- |
| 基础档 | 单元 4-6 | 单个页面，聚焦一类语法或指令 | 待补充 |
| 进阶档 | 单元 7-8 | 多组件协作，含状态提升与逻辑复用 | 待补充 |
| 综合档 | 单元 9-12 | 路由 + 状态 + 请求层贯通的小型应用 | 待补充 |

## 每个案例的目录约定

```

├── README.md     # 需求、涉及知识点、完成标准
```
