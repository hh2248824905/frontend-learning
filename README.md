# 前端工程化开发 · 配套教程

《前端工程化开发》48 学时课程（12 周）的配套学习材料，按课程的模块与单元编号组织。
内容从零讲起：每篇先给一个具体场景，再讲写法和原理，最后落到常见错误与练习。

## 目录

| 目录 | 篇数 | 内容 |
| --- | --- | --- |
| `00-课程导学` | 7 | 课程定位、学习方法、AI 使用边界、学习路线、环境准备、12 周地图 |
| `01-工程化认知与工具链` | 23 | 模块一 · 单元 1-3：工程化认知、Node 与包管理、Vite 构建、代码规范、Git 协作 |

| `03-组件化开发` | 19 | 模块三 · 单元 7-8：单文件组件、父子通信、插槽、组合式函数、自定义指令 |
| `04-应用架构` | 17 | 模块四 · 单元 9-10：路由、登录鉴权、Pinia、请求层封装、错误分层 |

| `09-附录` | 8 | API 速查、常见报错、版本清单、术语表、AI 工具速查、环境自检清单、问题记录表 |

## 从哪开始

按顺序读这几篇，把环境跑起来，再进单元：

1. [01-课程导读](docs/00-课程导学/01-课程导读.md) — 这门课学什么、怎么考核
2. [02-怎么用这套教程](docs/00-课程导学/02-怎么用这套教程.md) — 课前、课中、课后分别读什么
3. [05-开发环境准备](docs/00-课程导学/05-开发环境准备.md) — 装环境，跑通自检清单
4. [06-12 周课程地图](docs/00-课程导学/06-12-周课程地图.md) — 每周的任务与产出

## 每个单元的读法

每个单元目录内按顺序编号，跟着编号读即可：

```
00-单元导学.md      本单元要解决的问题、学时安排、对应岗位能力
01-…、02-…         知识点小节，每节末尾有「动手」和「常见问题」
AI-协作-….md       这一节内容里 AI 能做什么、哪里不能听它的
课后练习.md         作业与验收标准
```

正文里的示例代码都能直接跑。遇到报错先查 `docs/09-附录/02-常见报错与排查.md`。

## 关于发放

单元内的课堂演练案例、案例库、综合项目参考实现，会随课堂进度单独下发。
