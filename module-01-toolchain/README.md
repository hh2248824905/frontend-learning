# 模块一 · 工程化认知与工具链

12 学时，第 1-3 周。目标是建立工程化视角、搭好开发环境、把规范与协作流程固化下来。

| 单元 | 主题 | 目录 | 课堂产出 |
| --- | --- | --- | --- |
| 1 | 工程化认知、学习路线与开发环境 | `unit-01-env/` | 环境自检报告、学习路线图 |
| 2 | Node.js 生态、包管理与构建工具 | `unit-02-package-vite/` | 依赖排查单、可复用的 `vite.config.js` |
| 3 | 工程规范、质量保障与 Git 协作 | `unit-03-quality-git/` | 带校验钩子的工程模板、合并请求 + 流水线 |

单元的成果最终沉淀到 `templates/vue3-vite-starter/`。
